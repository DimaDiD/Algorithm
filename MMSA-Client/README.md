# MMSA-Client

Фронтенд сайту MMSA (React 18 + TypeScript, Create React App).

| Команда | Що робить |
|---|---|
| `npm install` | Встановити залежності |
| `npm start` | Запустити на http://localhost:3000 (API проксується на бекенд) |
| `npm test -- --watchAll=false` | Запустити тести один раз |
| `npm run build` | Зібрати продакшн-версію в `build/` |

Опційно: файл `.env` з `REACT_APP_CONTACT_EMAIL=...` — контакт на сторінці «Про сайт».

Загальний опис проєкту — у кореневому `README.md`.
